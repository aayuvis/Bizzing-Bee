## Voice synthesis

- **Word pronunciations** are synthesized with Google Cloud Text-to-Speech. The generated
  audio files are used under the Google Cloud terms of service; no attribution is
  required for synthesized output.
- **Lesson and story narration** is synthesized with the **Kokoro** text-to-speech model
  (kokoro-82M weights, Apache License 2.0; run via the MIT-licensed `kokoro-onnx`
  runtime). Only the generated MP3 audio ships with the app; the model itself is not
  distributed here.

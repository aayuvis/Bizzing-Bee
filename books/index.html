The Bizzing Bee Library

Fifteen graphic study books — ten across the full 122-chapter course, five bigger volumes for the Advanced Pack. Letter-size pages, print-ready.

Getting a book into Canva: download the PDF (button on each book), then in Canva choose Create a design → Import file (or drag the PDF onto the Canva home page). Canva converts every page into an editable design — text stays editable in most blocks. The HTML version is the print master; export it to PDF from the browser with margins set to None and background graphics on, or use the pre-rendered PDF next to it.

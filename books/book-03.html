Latin Prefixes

in- / im- / il- / ir- (not / without)

The big idea
Latin in- = not. It assimilates — changes shape — to match whatever consonant follows. This doubling is both a spelling signal and a meaning signal: the doubled letter reveals the hidden prefix.
The pro move
IRREFUTABLE
Say it. ih-ruh-FYOO-tuh-buhl Spell it. I · R · R · E · F · U · T · A · B · L · E Say it again. ih-ruh-FYOO-tuh-buhl Syllables. ih · rah · fyuw · tah · bah · l Sounds → Letters. [ih=IR] [REF=REF] [yuh=U] [tuh=TA] [bul=BLE] Exception. double-R from in+r assimilation; -able not -ible; stress on second syllable ih-REF-yuh-tuh-bul Origin. Latin Root. Latin in+refutare = not able to be refuted, from re+futare = to beat b

The Assimilation Rule

in- = not. Before l → il-: illegal, illegible, illicit. Before m/b/p → im-: impossible, immoral, impeccable. Before r → ir-: irregular, irrefutable, irrevocable. Before everything else → in-: insane, inimical, inexorable. The doubled first letter of the root IS the spelling signal.

High-Value im- Words

Impeccable (im- + pecca = sin) = without flaw. Imperturbable = cannot be disturbed. Impecunious (im- + pecunia = money) = penniless. Impetuous = without restraint, rash. Implacable (im- + placare = appease) = cannot be calmed or satisfied. Each carries "not/without" into rich vocabulary.

High-Value in- Words

Inexorable (in- + exorare = beg out of) = cannot be moved by pleading = relentless. Inimical (in- + amicus = friend) = not friendly = hostile. Inscrutable = cannot be understood. Innuendo (in- + nuendo = nodding toward) = an indirect suggestion. Ineffable = too great to express in words.

il- and ir- Words

Illicit (il- + licitus = allowed) = not permitted. ⚠️ Confusable with elicit (to draw out) — completely different word! Illusory = not real. Irascible = quickly angered. Irreverent = not respectful. Irremediable = cannot be fixed. Irrevocable = cannot be called back.

The Dangerous Exception

in- can ALSO mean "into/toward" (not just "not"): inflammable = catches fire easily — NOT fireproof! Invaluable = so valuable it cannot be measured = priceless, NOT worthless. Context and origin tell you which. When uncertain: get the definition before spelling.

Latin Prefixes

un- (not / reverse action)

The big idea
Old English/Latin un- = not (before adjectives) or reverse the action of (before verbs). The same two letters, two completely different jobs — word class determines meaning.
The pro move
UNCONSCIONABLE
Say it. uh-n-k-AH-n-sh-uh-n-uh-b-uh-l Spell it. U · N · C · O · N · S · C · I · O · N · A · B · L · E Say it again. uh-n-k-AH-n-sh-uh-n-uh-b-uh-l Syllables. u · n · c · o · n · s · c · i · o · n · a · b · l · e Sounds → Letters. [un=UN] [KON=CON] [shuh=SCION] [uh=A] [bul=BLE] Exception. -scion- = /shun/ from Latin conscientia; -able not -ible; stress on second syllable un-KON-shuh-nuh-bul Origin. Latin Root. Latin conscientia = moral sense (con=with + scire=know)

Two Jobs

un- before an adjective = "not": unkempt (not combed), unrequited (not returned), unprecedented (not before done). un- before a verb = "reverse": undo, unwrap, unravel. The same two letters — word class determines which meaning applies.

High-Value un- Adjectives

Unkempt (un- + kempt = combed). Unfettered (un- + fetter = chain) = not restrained. Unimpeachable = beyond reproach. Unscrupulous = without moral principles. Unwieldy = hard to handle. Unconscionable = shockingly unethical.

Spelling Signal — Double-N

When un- precedes a root starting with n, you get double-n: unnecessary = U-N-N-E-C-E-S-S-A-R-Y. Unnatural = U-N-N-A-T-U-R-A-L. Unnerve = U-N-N-E-R-V-E. The first n is the prefix; the second is the root. Not a doubling rule — just prefix meeting root.

un- vs in-

Both mean "not" but: un- is Old English/Germanic; in- is Latin. Unhappy (un- + Germanic). Infelicitous (in- + Latin felix = happy). The question "What language does this word come from?" at the microphone helps — Latin-origin words more often use in- negation, Germanic-origin words use un-.

Classic Bee un- Words

Unequivocal = not ambiguous. Unfathomable = cannot be fathomed/understood. Unprecedented = not before existing. Unrequited = love not returned. Unimpeachable = beyond any challenge. All negations of strong adjectives — and all with the simple, reliable U-N prefix.

Latin Prefixes

dis- (apart / not / opposite)

The big idea
Latin dis- = apart, not, or deprived of. When it meets a root beginning with s, the result is double-s. Recognizing this doubling is the key to spelling dissipate, dissolve, and dissemble correctly.
The pro move
DISINGENUOUS
Say it. dih-sih-NJEH-nyoo-uhs Spell it. D · I · S · I · N · G · E · N · U · O · U · S Say it again. dih-sih-NJEH-nyoo-uhs Syllables. dih · sih · njheh · nyuw · ah · s Sounds → Letters. [dis=DIS] [in=IN] [JEN=GEN] [yoo=U] [us=OUS] Exception. BOTH dis- AND in- are prefixes here; -gen- = birth/kind; -uous not -eous; stress: dis-in-JEN-yoo-us Origin. Latin Root. Latin dis- = not + ingenuus = freeborn, frank, candid

What dis- Does

dis- = apart, not, or deprive of. Dissonance (dis- + sonus = sound apart) = harsh discord. Discern (dis- + cernere = separate) = separate truth from error. Disdain (dis- + dignare = deem worthy) = think something not worthy. Disparity = lack of equality. Dissemble = disguise one's true appearance.

dis- + s-root = double-s

When the root begins with s, you get dis- + s- = diss-: dissipate (scatter apart), dissolve, dissent, dissertation, dissemble, disseminate (dis- + semen = seed = scatter seeds of ideas). The double-s is the dis- prefix meeting a root that starts with s.

Spellings That Trap

Discernible = discern + -ible (use -ible because discern is from Latin — the stem cannot stand alone). Distraught = dis- + trahere = pulled apart = extremely upset — note the -aught from Old English. Disingenuous = dis- + in- + gen — two negating prefixes stacked.

dis- vs de-

Both weaken or remove things. dis- = separation or absence. de- = removal or reversal. Disarm = remove the ability to use arms. Dearm = not a word. Disintegrate = fall apart. Decompose = break down chemically. Disagree = the opposite of agree.

High-Value dis- Words

Disparage = speak with disdain. Dissonance = lack of harmony. Discrepancy = a gap between things. Disconcert = unsettle. Discomfit = defeat or thwart. ⚠️ Discomfit ≠ discomfort — discomfit means to defeat, not merely to make uncomfortable. A classic vocabulary-round distinction.

Latin Prefixes

de- (down / away / reverse)

The big idea
Latin de- removes, reverses, takes down, or completely intensifies. It is one of the most stable Latin prefixes — it never assimilates. The challenge is always what comes after de-.
The pro move
DESICCATE
Say it. d-EH-s-uh-k-ay-t Spell it. D · E · S · I · C · C · A · T · E Say it again. d-EH-s-uh-k-ay-t Syllables. d · e · s · i · c · c · a · t · e Sounds → Letters. [DES=DES] [ik=IC] [kayt=CATE] Exception. double-C from Latin desiccare (inherited, not from prefix meeting root); silent final -e; DES-ih-kayt Origin. Latin Root. Latin desiccare = to dry up, from de-(completely)+siccare(to dry)+sicc

What de- Does

de- removes (decaffeinate, defrost), reverses (decode, decompose), goes down (descend, decline), or means thoroughly (devout, demolish). Desiccate = de- + siccus (dry) = remove all moisture. Denouement (de- + French nouer = untie) = the final unraveling of a story's plot.

de- Removing Words

Decimate = de- + decimus (tenth) = originally kill one in ten (Roman military punishment); now: destroy a large portion. Denigrate = de- + niger (black) = blacken someone's reputation. Deracinate = de- + radix (root) = uproot entirely. Denude = strip completely bare.

French de- Words

Many French loanwords begin de-: Demesne (an estate's private land), Demitasse (demi = half + tasse = cup = small coffee cup), Débâcle (sudden collapse), Débonnaire/Debonair (from de bon aire = of good air = charming). The accent often disappears in English but the spelling stays.

de- vs dis-

de- = reversal or removal; dis- = separation or absence. Decode = reverse the coding. Disagree = the opposite of agree. Defrost = remove frost. Disintegrate = fall apart. Both prefixes weaken or oppose — the nuance is direction vs absence.

Spelling Details

Desiccate = D-E-S-I-C-C-A-T-E — the double-c is from the Latin siccare, not from prefix meeting root. Denouement = D-E-N-O-U-E-M-E-N-T (French -ou- vowel pair). Deign = D-E-I-G-N (silent g from Old French). Deft — de- here is part of an Old English root, not the Latin prefix.

ex- / e- / ef- (out / former / thoroughly)

The big idea
Latin ex- = out of. It appears as ex-, e-, or ef- depending on what follows. Before f it assimilates to ef-; before many consonants the x drops to just e-. Same prefix, three shapes.
The pro move
EFFERVESCENT
Say it. eh-f-ur-v-EH-s-uh-n-t Spell it. E · F · F · E · R · V · E · S · C · E · N · T Say it again. eh-f-ur-v-EH-s-uh-n-t Syllables. e · f · f · e · r · v · e · s · c · e · n · t Sounds → Letters. [ef=EF] [fer=FER] [VES=VES] [ent=CENT] Exception. ef- = ex- before f (assimilation gives double-f); -escent = becoming; stress on third syllable ef-fer-VES-ent Origin. Latin Root. Latin effervescere = to boil up, from ex-(out)+fervere = to boil

Three Forms

ex- before vowels and most consonants: exquisite, extraneous. Before f → ef-: effervescent (ef- + fervere = boil = bubbling over), efface (ef- + facies = face = rub out). Before many consonants the x drops to e-: eloquent, elaborate, elicit, emit.

Out-Of Words

Excoriate (ex- + corium = skin) = strip the skin = criticize savagely. Exculpate (ex- + culpa = fault) = free from blame. Exigent (ex- + agere = drive out) = pressing, urgent. Exiguous = extremely scanty. Expatiate = speak at great length. Expunge (ex- + pungere = prick) = erase entirely.

Former / From Words

Ex- before a title = former: ex-president. Expatriate = one who has left their homeland. Extirpate = pull out by the roots. Exhume (ex- + humus = earth) = dig out of the ground.

Thorough / Intensive ex-

ex- intensifies the root: exacerbate = make thoroughly more bitter/worse. Exasperate = thoroughly roughen = irritate deeply. Excruciating (ex- + crux = cross) = thoroughly cross-like = intensely painful. Exhilarating = thoroughly lift the spirits.

Spelling Traps

Exquisite = E-X-Q-U-I-S-I-T-E (not exquissite). Extemporaneous = E-X-T-E-M-P-O-R-A-N-E-O-U-S — from ex tempore = out of the moment. Extraordinary = E-X-T-R-A-O-R-D-I-N-A-R-Y — note: extra- here not ex-! Different prefix entirely.

The big idea
Latin re- = again or back. One of the most common prefixes in English. But beware: not every word starting with re- uses it as a prefix — sometimes it is part of the root itself.
The pro move
RECALCITRANT
Say it. r-ih-k-A-l-s-ih-t-r-uh-n-t Spell it. What re- Does

re- = again (redo, restart) or back (return, retract). Recalcitrant (re- + calcitrare = kick) = kicking back = stubbornly resistant. Redoubtable (re- + douter = fear) = worth fearing again and again. Repartee = a quick, ready reply. Recidivism (re- + cadere = fall) = falling back into crime.

pre- / pro- (before / forward)

The big idea
Latin pre- = before in time or position. Latin pro- = forward, in favor of, on behalf of. Two prefixes, closely related in meaning, producing very different vocabularies.
The pro move
PROPITIOUS
Say it. p-r-uh-p-IH-sh-uh-s Spell it. P · R · O · P · I · T · I · O · U · S Say it again. p-r-uh-p-IH-sh-uh-s Syllables. p · r · o · p · i · t · i · o · u · s Sounds → Letters. [pruh=PRO] [PISH=PI] [us=TIOUS] Exception. -tious = /shus/ (Latin -tiosus); -pit- from pietas = favor; stress on second syllable pruh-PISH-us Origin. French Root. pre- = Before

Precocious (pre- + coquere = cook) = cooked before its time = unusually mature early. Precursor = one who runs before. Prescient (pre- + scire = know) = knowing before it happens. Preponderant (pre- + ponderare = weigh) = weighing more = dominant. Prevaricate = straddle before = dodge the truth.

pro- = Forward / For

Propitious (pro- + pietas = favor) = presenting favorable signs ahead. Prodigious = extraordinarily great. Provenance (pro- + venire = come) = where something came from. Protagonist (pro- + Greek agonist = actor) = the forward-acting main character. Profligate = wildly extravagant.

Precocious = P-R-E-C-O-C-I-O-U-S (two c's; the first comes from prefix + root). Prescience = P-R-E-S-C-I-E-N-C-E (the sc- cluster from scire). Predilection = P-R-E-D-I-L-E-C-T-I-O-N — note -lection not -lekshun.

Prescribe vs Proscribe

Prescribe (pre- + scribere = write before) = a doctor writes a prescription in advance. Proscribe (pro- = put forward publicly) = ban or forbid. A doctor prescribes; a government proscribes. Precede (come before) vs proceed (move forward). Same-sounding prefixes, opposite directions.

Prodigal & Prodigious

Prodigal (prodigere = drive forward wastefully) = wastefully extravagant. Prodigious (prodire = go forward beyond normal) = extraordinarily great in size or degree. Both from pro- but from different Latin roots — the definitions distinguish them clearly at the bee.

The big idea
Latin sub- = under. It assimilates just like ad- and in-. Its opposite super- = above/beyond. Recognizing the doubled letter in sur-/suf-/sug-/sup- forms reveals the hidden sub- prefix.
The pro move

sub- = under. Before r → sur-: surreptitious (sub- + reptus = seized) = seized from under = done secretly. Surfeit = sub- + French fait = overdone = excess. Before f → suf-: suffice, suffuse. Before g → sug-: suggest. Before p → sup-: supplant, suppress.

Surreptitious = double-r from sur- + r-root. Supersede = -sede not -cede — unique in English. Surfeit = S-U-R-F-E-I-T (-ei- from French). Supplant = sup- + planta (sole of foot) = trip up = replace — not sub-plant!

The big idea
Latin com- = with, together. Like ad- and in-, it assimilates to match the root. The doubled letter in the resulting word IS the prefix meeting the root — the spelling tells you the origin.
The pro move
CONNOISSEUR

com- = with. Before l → col-: collaborate, collateral, colloquy. Before r → cor-: correlate, corroborate, corrupt. Before b/m/p stays com-: combine, commiserate, compel. Before vowels/most others → con-: contrite, conciliate. The doubled letter signals the assimilation.

Collaborate = work together. Colloquy = speak together formally. Corroborate (cor- + robur = strength) = strengthen together = confirm evidence. Corrugated (cor- + ruga = wrinkle) = wrinkled together = ridged. Double-ll or double-rr IS the assimilation.

Hardest Words

Connoisseur = C-O-N-N-O-I-S-S-E-U-R (double-n AND double-s AND French -eur). Commemorate = C-O-M-M-E-M-O-R-A-T-E (double-m). Continuum = C-O-N-T-I-N-U-U-M (double-u from Latin). These compound difficulty by combining assimilation doublings with additional Latin or French patterns.

The big idea
Latin malus = bad, evil. mal- is a reliable negative signal — every word it touches is associated with badness, illness, or wrongdoing. And it never assimilates: always spelled M-A-L.
The pro move
MALFEASANCE
Say it. m-a-l-f-EE-z-uh-n-s Spell it. M · A · L · F · E · A · S · A · N · C · E Say it again. m-a-l-f-EE-z-uh-n-s Syllables. m · a · l · f · e · a · s · a · n · c · e Sounds → Letters. The mal- Signal

Latin malus = bad, evil. Malfeasance = doing bad things in an official capacity. Malevolent (mal- + velle = wish) = wishing evil. Malicious = harboring ill intent. Malignant = growing in a harmful way. Maladroit (mal- + French adroit = skillful) = clumsy. Every mal- word carries its Latin warning.

Perfect Opposites

Every mal- word has a ben- counterpart: malevolent ↔ benevolent. Maleficent ↔ beneficent. Malignant ↔ benign. Malediction ↔ benediction. Knowing one side of each pair = knowing both. In a bee, if you know the ben- word, swap the prefix.

Malaise & Malaria — Etymology is History

Malaise (mal- + French aise = ease) = general feeling of being unwell. Malaria (mal- + Italian aria = air) = bad air — Italians blamed swamp air before mosquitoes were discovered. Word etymology literally records how humans once understood the world.

Maladroit & Malapropism

Maladroit (mal- + French adroit = skillful) = clumsy, lacking skill. Malapropism (mal- + French à propos = to the purpose) = a word wrongly used in place of a similar-sounding one. Example: "for all intensive purposes" instead of "for all intents and purposes."

Medical mal- Words

Malignant = growing harmfully (opposite of benign). Malnutrition = insufficient or wrong nutrition. Malpractice = wrong professional practice. Malformation = wrong or abnormal formation. Malabsorption = poor absorption of nutrients. In medicine, mal- always signals something going wrong with the body's normal function.

mis- (wrongly / badly)

The big idea
Latin/Old English mis- = wrongly, badly, or astray. When it meets a root beginning with s, the result is double-s. ⚠️ This is NOT the same as Greek misos (hatred) — same spelling, completely different origin.
The pro move
MISCHIEVOUS
Say it. m-IH-s-ch-uh-v-uh-s Spell it. M · I · S · C · H · I · E · V · O · U · S Say it again. m-IH-s-ch-uh-v-uh-s Syllables. m · i · s · c · h · i · e · v · o · u · s Sounds → Letters. [MIS=MIS] [chiv=CHIE] [us=VOUS] Exception. only 3 syllables: MIS-chiv-us — NOT mis-CHIEV-i-ous which is the most common mispronunciation error Origin. Anglo-Norman Root. Old French meschever = to meet with misfortune

What mis- Signals

mis- = done wrongly or badly. Miscellaneous (mis- + cella = room) = mixed into wrong rooms = varied kinds. Mischievous = mis- + chevir = achieving wrongly. ⚠️ MIS-chiev-ous = 3 syllables, NOT mis-CHIEV-i-ous = 4. The 4-syllable pronunciation is wrong and wrong spelling often follows it.

High-Value mis- Words

Miscreant (mis- + credere = believe wrongly) = villain. Misnomer (mis- + nomen = name) = a wrongly applied name. Misprision = wrongful concealment of knowledge of a crime. Misconstrue = interpret wrongly. Misanthrope starts with mis- but is Greek misos (hatred) — a different root entirely.

Miserable (miser = wretched in Latin) — the mis- is part of the root, not a prefix. Mistletoe = from Old English misteltan — the mis- is part of the ancient word. Test: remove mis- — if the remainder is not a standard English word, mis- is probably part of the root.

mis- vs dis-

Both can mean "badly/not" but: mis- = done in a wrong way; dis- = apart or the opposite of. Misguide = guide wrongly. Disuse = no longer in use. Misuse = use wrongly. Displace = move to a wrong place. Both prefixes describe something going wrong — the nuance is method (mis-) vs absence (dis-).

inter- / intra- (between / within)

The big idea
Latin inter- = between two or more things. Latin intra- = inside or within one thing. One letter changes the entire meaning. Keeping them straight is one of the most useful vocabulary distinctions in English.
The pro move
INTRANSIGENT
Say it. ih-n-t-r-A-n-s-uh-j-uh-n-t Spell it. I · N · T · R · A · N · S · I · G · E · N · T Say it again. ih-n-t-r-A-n-s-uh-j-uh-n-t Syllables. i · n · t · r · a · n · s · i · g · e · n · t Sounds → Letters. [in=IN] [TRAN=TRAN] [suh=SI] [jent=GENT] Exception. intra- + transigere = drive through; -ent not -ant; note: this uses intra- not inter-; stress: in-TRAN-suh-jent Origin. French Root. The Essential Distinction

inter- = between (separates two things). intra- = within (contains within one thing). International = between nations. Intramural = within the walls of one school. Intercollegiate = between colleges. Intravenous = within the vein. One letter. Entirely different meaning.

Key inter- Words

Intermezzo (inter- + Italian mezzo = middle) = piece played between acts. Intercede (inter- + cedere = go) = go between parties to help. Interpolate (inter- + polire = polish) = insert something between existing material. Internecine (inter- + nex = death) = destructive to both sides.

Key intra- Words

Intransigent (intra- + transigere = drive through) = not willing to move = stubbornly uncompromising. Intravenous = within the vein. Intracranial = within the skull. Intractable = not able to be handled. ⚠️ Intractable uses in- (negation) not intra- — always check before assuming!

Confusables

Interpolate (insert between) vs extrapolate (extra- = outside = extend beyond known data — entirely different prefix and meaning). Interloper (inter- + Dutch lopen = run between) = one who intrudes. Interregnum (inter- + regnum = reign) = period between rulers — no doubling here.

Spelling the inter-/intra- Words

The big idea
Latin ab- = away from, off, or down from. Before s and t it becomes abs-. Before v it shortens to a-. One of the cleanest-meaning prefixes in Latin: it always signals departure.

ab- = Away From

All three move away from something. ab- = departing from. de- = going down from or reversing. ex- = out of. Abhor = shrink away from with disgust. Detest = hate thoroughly. Exclude = shut out. The prefix marks direction and intensity of the movement away.

ad- (toward / near) — the Great Assimilator

The big idea
Latin ad- = toward, near, in addition to. It is the most enthusiastic assimilator in Latin — it changes its final d to match whatever consonant follows, doubling it in the process. The doubled letter IS the prefix.
The pro move
ASSIDUOUS
Say it. uh-SIH-dwuhs Spell it. A · S · S · I · D · U · O · U · S Say it again. uh-SIH-dwuhs Syllables. ah · sih · dwah · s Sounds → Letters. [uh=AS] [SIJ=SID] [oo=U] [us=OUS] Exception. double-S from ad+s assimilation (ad+siduous → assiduous); -uous not -ious; stress: uh-SIJ-oo-us Origin. Latin Root. Latin 'assiduus' = constantly present, from 'assidere' = to sit beside

The Full Assimilation Chart

ad- + consonant → double that consonant. Before c/q → ac-: acquire, acquiesce. Before f → af-: affect, affirm. Before g → ag-: aggrandize, aggravate. Before l → al-: alleviate, allure. Before n → an-: annotate, annihilate. Before p → ap-: appease, append. Before r → ar-: arraign. Before s → as-: assiduous, assimilate. Before t → at-: attenuate, attrition.

ac- Words

Acquiesce (ac- + quiescere = rest) = agree without protest. Accolade (ac- + French col = neck) = embrace/award. Acquit (ac- + quietare = set at rest) = declare not guilty. Accrue (ac- + crescere = grow) = accumulate over time. Double-c is the ac- assimilation signal.

al- Words

Alleviate (al- + levis = light) = make lighter = ease pain. Allure (al- + lure) = draw toward with appeal. Allude (al- + ludere = play) = hint toward. Allocate (al- + locus = place) = assign toward a purpose. Double-l is the al- assimilation signal.

ap- Words

Appease (ap- + pacare = pacify) = satisfy a demand. Approbation (ap- + probare = prove) = formal approval. Append (ap- + pendere = hang) = add on. Appropriate = ap- + proprius = take for one's own use. Double-p is the ap- assimilation signal.

as- and at- Words

Assiduous (as- + sedere = sit) = diligently attending = persistently hardworking. Assimilate (as- + similis = like) = absorb and become like.

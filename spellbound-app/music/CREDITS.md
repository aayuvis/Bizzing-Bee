# Music credits — Bizzing Bee

All music in Bizzing Bee is **composed in code for Bizzing**. There are no audio files, no
samples and no third-party recordings, so there is nothing to license.

| Loop | Where it plays | Written as |
|---|---|---|
| Home | Home | `music.js` → `SCORE.home` |
| Games | the Arcade, the Mock Spelling Bee, Bee Trivia | `SCORE.games` |
| Bizzing Bee | world 1, on the Atlas and around the app | `SCORE.spellbound` |
| Galaxy | world 2 | `SCORE.aurora` |
| Blade | world 3 | `SCORE.anime` |
| Lab | world 4 | `SCORE.science` |
| Elements | world 5 | `SCORE.avatar` |
| God's Abode | world 6 | `SCORE.godly` |
| Race Zone | world 7 | `SCORE.race` |
| Dino Era | world 8 | `SCORE.dino` |

- **Source:** composed in code for Bizzing (FIX-BEE v2, 2 Oct 2026). Each loop is a tempo, a key,
  an eight-bar chord progression played A A B A over 32 bars, a bass pattern, two melodic
  motifs and a light percussion part, rendered live with the Web Audio API. Loops run 60–88 s
  and repeat seamlessly.
- **Licence:** © Bizzing. No third-party material.
- **World entry stings** (`app-art/*-stinger.mp3`, the opening splash) were synthesised for
  Bizzing earlier (see CLAUDE.md, "The opening splash") — also no third-party recordings.
